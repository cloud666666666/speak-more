# 客户端热词文件
# 使用音素 RAG 匹配，支持中英文混合
# 具备强制性，相似度高于阈值的一定会被替换
# 井号开头的行为注释，会被忽略
# 每行一个热词，可以用 | 分割添加多个别名
# 在 `~~~` 后面添加用 | 分隔的黑名单，可阻止错误的替换
#
# 详细说明见 docs/热词功能如何使用.md

# ====== 机器人 / 具身智能 ======
# 别名只写**实际会听错的样子**，不写"半个正式名"。
# 反例：别写 `宇树科技 | 宇树`，那会让用户说"宇树"时也被补成"宇树科技"。
# 反过来也别写 `云深处 | 云深处科技`，那会把完整的"云深处科技"截短成"云深处"。
宇树科技 | 雨树科技 | 语数科技 | 与数科技 | 语书科技
云深处
